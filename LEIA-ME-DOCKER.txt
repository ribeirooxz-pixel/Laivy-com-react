LAIVY (TCC)
Como rodar via Docker
=============================================

Pré-requisito: Docker Desktop instalado e aberto.
(Guia completo de instalação do Docker: peça o link ao Iago.)

Passos:

1. Extraia esta pasta (laivy-tcc-docker) em qualquer lugar do computador.

2. Abra o Terminal (Mac/Linux) ou PowerShell (Windows) dentro desta pasta.

3. Rode:

   docker compose up --build

   (na primeira vez demora alguns minutos - ele baixa as imagens e
   compila o projeto. Nas próximas vezes é bem mais rápido.)

4. Quando aparecer no terminal algo como "Started ProjetoApplication",
   abra no navegador:

   http://localhost:8080/login

5. Login: as contas iniciais (admin, treinador, atleta) recebem uma senha
   temporária na primeira subida. Veja com:

   docker logs laivy-backend | grep "Senha padrao"

   O sistema pede uma senha nova no primeiro acesso.

Para parar tudo: Ctrl+C no terminal, depois "docker compose down".
Os dados ficam salvos (volumes do Docker) entre uma execução e outra.

Antes da primeira vez: copie .env.example para .env e troque os valores
(depois, "python3 scripts/rotacionar-segredos.py" gera segredos fortes).
Este modo é só para desenvolvimento (http://localhost). Para colocar num
servidor de verdade, siga o DEPLOY.md.
